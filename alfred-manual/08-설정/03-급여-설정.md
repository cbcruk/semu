# 급여 설정

> 원문: https://support.alfred.kr/ba9e8268-560a-82ab-8e5b-813ff19d4d33

> **급여 설정**에서는 급여 계산의 기준이 되는 회사 정책을 설정합니다. 여기서 설정한 근로 조건·근로시간·급여·지급/공제 정책에 따라 매월 급여 카드가 자동으로 생성되고 계산됩니다.

**이 메뉴에서 할 수 있는 일**

- 근로 조건, 근로시간 정책, 급여 정책, 지급 항목, 공제 항목 설정
- 회사 정책에 맞춘 급여 계산 기준 관리

**경로:** 설정 > 급여 정보 > 급여 설정

**노출 대상:** 급여 구독 고객

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A81b7dc1f-b6b1-4948-b91c-636b4f58f33f%3Aimage.png&blockId=39de8268-560a-800c-8f41-c95071249a60)

### 급여 설정 5가지 항목

>

**① 근로 조건 → ② 근로시간 정책 → ③ 급여 정책 → ④ 지급 항목 → ⑤ 공제 항목**

각 항목을 회사 정책에 맞춰 설정합니다. 아래에서 항목별 설정 방법을 자세히 확인할 수 있습니다.

---

### 1. 근로 조건

`근로 조건 추가하기 +` 버튼을 클릭한 후, 아래 네 가지 항목을 입력합니다.

- 근로 조건 이름
- 근무 장소
- 수습 기간
- 지급률

| 구분 | 근로 조건 이름 | 근무 장소 | 수습 기간 | 지급률 |
| --- | --- | --- | --- | --- |
| 예시1 | 정규직 | 본사 | 3개월 | 100% |
| 예시2 | 인턴 | 본사 | 없음 | - |
| 예시3 | 원격근무 | 본사 및 회사가 지정하는 장소 | 1개월 | 90% |

근로계약서에서 근로계약기간·수습기간·지급률·근무장소를 확인해 입력하며, 계약서 내용을 기반으로 근로 조건을 동기화할 수 있습니다.

> - 근로계약서 확인사항  근로계약기간, 수습기간, 지급률, 근무장소
>

>
> - Alfred  계약서 내용을 기반으로 근로 조건 동기화
>
> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A9601b7ac-ef2b-47ad-b31d-db0726545e70%3Aimage.png&blockId=39de8268-560a-8007-9cff-f35695b095a5)

### 2. 근로시간 정책

`정책 추가하기 +` 버튼을 클릭한 후, 근로시간 정책명·휴일·소정근로시간·고정 시간외 근로시간을 설정합니다.

- 근로시간 정책 설정 자세히 보기

  **(1) 근로시간 정책명 & 휴일**

  - 근로시간 정책명: 회사 근무 형태에 맞게 입력 (예: 정규직, 정규직(연장 10h), 정규직 7.5시간)
  - 휴일: 유급 주휴일(예: 일요일), 무급 휴무일(예: 토요일)

  >

  **(2) 소정근로시간 설정**

  근무주기 방식과 주휴시간을 입력해 설정합니다.

  근무주기 방식

  | 구분 | 설명 | 예시 |
  | --- | --- | --- |
  | 매주 | 근무 요일·시간의 변동이 없는 경우 | 월-금 8시간 / 화-토 7시간 |
  | 격주 | 2주 단위로 요일·시간 변동이 있는 경우 | 첫째·셋째주 월-금 / 둘째·넷째주 월-토 |
  | 월 1회 | 월 단위로 요일·시간 변동이 있는 경우 | 첫째주 수요일 오전 / 마지막주 토요일 4시간 추가 |

  주휴시간 입력

  | 구분 | 설명 |
  | --- | --- |
  | 자동 계산 | 근무 주기에 따라 근로시간을 입력하면 주휴시간 자동 계산 |
  | 직접 입력 | 회사 정책에 따른 주휴시간을 개별 입력 |

  **(3) 고정 시간외 근로시간**

  입력 방식과 시간 기준을 설정합니다.

  입력 방식

  | 구분 | 설명 | 예시 |
  | --- | --- | --- |
  | 없음 | 고정 시간외 근로가 없는 경우 | - |
  | 요일별 | 특정 요일에만 발생 | 매주 수요일 3시간 연장 |
  | 주간합계 | 1주 단위로 발생 | 1주 기준 5시간 연장 |
  | 월간합계 | 한 달 단위로 발생 | 월 30시간 연장 + 10시간 야간 |

  - 주간합계: 주 52시간제 대응에 용이하나 주 단위 근태 관리·정산 업무가 늘 수 있음
  - 월간합계: 연장 근로 배분이 유동적이나 실제 초과 근로 시간 관리가 소홀해질 수 있음

  >

  시간 기준

  | 구분 | 설명 |
  | --- | --- |
  | 실근로 시간 | 가산 배수를 적용하기 전의 실제 시간외 근로시간 |
  | 가산 근로 시간 | 연장·야간·휴일·휴일연장에 가산 배수를 적용한 시간 (5인 이상 사업장 기준) |

  실근로 시간에 따른 가산 근로 시간 산정 예시

  | 구분 | 실근로 시간 | 가산 근로 시간 (배수 적용) |
  | --- | --- | --- |
  | 고정 연장 근로 | 20시간 | 20시간 × 1.5배 = 30시간 |
  | 고정 야간 근로 | 10시간 | 10시간 × 0.5배 = 5시간 |
  | 고정 휴일 근로 | 8시간 | 8시간 × 1.5배 = 12시간 |
  | 고정 휴일 연장 근로 | 2시간 | 2시간 × 2배 = 4시간 |

  >

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A3c6ce3e3-f778-4b3f-9537-ddd10599ad8c%3Aimage.png&blockId=39de8268-560a-80a7-998d-dcf4fe4ed3aa)

### 3. 급여 정책

기본·수당 지급배수·퇴직금·귀속연도 최저임금 기준 4가지 항목을 설정합니다.

- 급여 정책 설정 자세히 보기

  **(1) 기본**

  - 임금산정 기간: 임금을 산정하는 기간 (예: 매월 1일~말일, 매월 15일~익월 14일)
  - 임금지급 시기: 급여일이 당월/익월 며칠에 지급되는지 설정
  - 임금지급방법: 계좌이체 / 직접지급
  - 근태기록연동: 연동 / 미연동

  > ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A7a76b103-7e56-40e4-858b-9e9139d6bfb9%3Aimage.png&blockId=39de8268-560a-8095-99fd-c9cf9d2f0fdf)

  >

  **(2) 수당 지급배수**

  5인 미만 또는 5인 이상 사업장 여부를 선택한 후 4가지 수당의 지급배수를 설정합니다.

  > **[5인 미만]**
  >
  > **근로기준법 제56조(연장·야간 및 휴일 근로)의적용을 받지 않으므로**, 추가 근로에 대한 지급배수 적용
  >
  > ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3Ac0622f0b-20e4-4885-9e1a-566e5e5dc4bc%3Aimage.png&blockId=39de8268-560a-80f3-91a8-da1d0821ba74)
  >
  > **[5인 이상]**
  >
  > **근로기준법 제56조(연장·야간 및 휴일 근로)의적용 대상**이므로 법정 근로시간을 초과하거나 특수한 시간대에 근무한 경우 반드시 추가 근로에 대한 지급배수 적용
  >
  > ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A8b932305-c167-4ba9-a764-440b002b7a7d%3Aimage.png&blockId=39de8268-560a-807c-a9d7-ce8234353208)
  >
  > 해당 이미지는 5인 미만·이상 사업장 기준 법정 수당 지급 배수의 예시이며, **항목별 가산 배수는 회사 정책에 따라 다를 수 있으므로 정책 확인 후 설정**해야 합니다.

  >

  **(3) 퇴직금**

  퇴직금·퇴직연금DB형·퇴직연금DC형 3가지 중 회사가 운영 중인 유형을 선택합니다.

  > ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3Acb77fc69-6d50-45e5-8a04-6f4a5275b89c%3Aimage.png&blockId=39de8268-560a-80ef-8bf8-c8612699ff23)

  **(4) 귀속연도 최저임금 기준**

  회사 설정 시 기본으로 반영되는 항목으로, 별도 입력 없이 확인만 진행합니다.

  > ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A36834a09-a07c-471f-a5c2-27d3ab71542e%3Aimage.png&blockId=39de8268-560a-805f-a170-f75668cd0ee8)

### 4. 지급 항목

`지급 항목 추가하기 +` 버튼을 클릭한 후, 두 가지 방식 중 하나를 선택해 설정합니다.

| 구분 | 설명 |
| --- | --- |
| 항목 불러오기 | 대부분의 지급 항목이 포함되어 있어 우선 활용 권장 |
| 직접 입력 | 불러오기 항목에 없는 경우 직접 입력하여 추가 |

>

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A75400daf-4778-43b9-a19f-335e90bcbcd0%3Aimage.png&blockId=39de8268-560a-80db-a004-d8ffe5377aa8)

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A2f1538cc-8e14-4363-816a-7c28f5d52018%3Aimage.png&blockId=39de8268-560a-80a9-8942-e57cc1221d3b)

- 지급 항목 세부 설정 자세히 보기

  지급 항목 선택 후 아래 항목을 회사 정책에 맞춰 설정합니다.

  - 금액
  - 월급여 포함 여부
  - 통상시급 포함 여부
  - 평균임금 포함 여부
  - 최저시급 포함 여부
  - 임금명세서에 계산방법 표기 여부 (표기 시 계산방법 입력)

    | 구분 | 입력 기준 |
    | --- | --- |
    | 금액 | 전 직원에게 동일하게 지급되는 금액이 아니면 입력하지 않음 |
    | 비과세 항목 | 비과세 한도금액을 추가로 입력 |
    | 연차휴가 항목 | 항목 불러오기로 선택하고 계산식을 직접 입력 |

### 5. 공제 항목

각 공제 항목의 산출방법 등을 회사 정책에 맞춰 설정합니다.

- 공제 항목 설정 자세히 보기

  **(1) 국민연금**

  - 고지기준: 고지 금액 스크래핑을 통해 공제
  - 취득월 납부 여부 (미희망 / 희망)

  **(2) 건강보험·고용보험**

  - 고지기준: 보수월액 기반으로 동일 보험료를 고지하는 방식 (급여 관리·행정 처리 간소화, 다만 퇴사·보수총액신고 이후 정산보험료 부담 발생)
  - 요율기준: 실 지급액 기반으로 공제하는 방식 (정산 부담 최소화, 변동 급여가 많은 사업장에 유리)

  >

  **(3) 근로소득세**

  | 구분 | 설명 |
  | --- | --- |
  | 간이세액표 기준 | 국세청 간이세액표에 따라 자동 산출 |
  | 직접 입력 | 회사 정책에 따라 금액을 직접 입력 |
  | 미적용 | 근로소득세 공제를 적용하지 않음 |

  **(4) 공제 항목 추가하기**

  위 항목 외에 추가로 공제 항목을 설정하려면 `공제 항목 추가하기 +` 버튼을 클릭합니다.

  - 직접입력: 공제 금액을 직접 입력하여 설정
  - 정산 시 입력: 정산 시점에 급여대장에서 금액을 입력

    > ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A21f162e1-4316-4c9e-abf2-fe7943709b1c%3Aimage.png&blockId=39de8268-560a-8089-9f7d-cb563dd07575)

### FAQ. 자주 묻는 질문

**급여 설정은 언제 하나요?**

회사를 처음 설정할 때 5가지 항목을 모두 설정합니다. 이 설정을 기준으로 매월 급여 카드가 자동 생성되므로, 정책 변경이 있을 때마다 업데이트해 주세요.

**급여일이 2개 이상인데 어떻게 설정하나요?**

현재 복수 급여일은 설정할 수 없어, 기준이 되는 주요 급여일 하나만 설정합니다. 인원수가 많거나 대표적인 급여일로 설정하는 것을 권장합니다.

**5인 미만 사업장인데 수당 지급배수를 꼭 설정해야 하나요?**

5인 미만 사업장은 근로기준법 제56조 적용을 받지 않아 추가 근로 지급배수가 적용되지 않습니다. 사업장 규모를 정확히 선택하면 그에 맞게 반영됩니다.

**비과세 항목명을 자유롭게 입력해도 되나요?**

비과세·연차수당 항목은 세무사랑 코드 연동과 계산식 연결을 위해 반드시 표준 항목명을 사용해야 합니다. `항목 불러오기`로 선택하는 것을 권장합니다.
