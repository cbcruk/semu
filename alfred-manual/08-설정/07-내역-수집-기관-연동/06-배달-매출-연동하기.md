# 배달 매출 연동하기

> 원문: https://support.alfred.kr/21fe8268-560a-81c3-af1f-ce8f79614f7c

### 배달 매출 조회 / 연동 바로가기

**배달 매출 조회하기 (거래조회 > 매출조회)**

[Heum Report https://report.heumtax.com/transactions/sales/delivery](https://report.heumtax.com/transactions/sales/delivery)

**배달 매출 연동하기 (레포트 기관연동)**

[Heum Report https://report.heumtax.com/integrate/transaction](https://report.heumtax.com/integrate/transaction)

### 연동방법 안내

1. **내역 수집 기관연동 >배달 매출 > 연동할 배달 앱 클릭**

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A3c9048b9-0a99-4483-9eea-fcca1f2099b1%3A%EB%B0%B0%EB%8B%AC%EC%97%B0%EB%8F%99.png&blockId=235e8268-560a-8026-b09c-d6b2bcc86f0a)

1. 해당 배달앱 **ID/PW를 입력**합니다.

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A56933d68-8074-4250-a884-e352f224e05c%3A%EB%A1%9C%EA%B7%B8%EC%9D%B8.png&blockId=21fe8268-560a-819e-8b76-f5c67c3b8325)

  - 연동이 완료되면 최근 90일의 배달 매출 데이터가 업데이트 됩니다.
  - 매일 오전 10시경 이전 5일치 매출이 업데이트 됩니다. (오늘 발생 매출은 내일부터 확인가능)

### 연동 후 기능 활용하기

- 레포트 **매출거래 > 배달** 페이지에서 연동된 배달앱 매출 내역을 한눈에 확인 할 수 있습니다.
  - 수수료, 배달료 등이 제외되지 않은 고객의 주문(결제)금액을 기준으로 합니다.
  - 배달 매출 조회 기능 안내 [바로가기](https://helpdesk.heumtax.com/1c1e8268-560a-80f7-9284-f60a6a7090cc)

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A6a8c4e71-f6ba-495f-8df2-7546c4177166%3ABD2.png&blockId=21fe8268-560a-8129-aa54-f10eeae4b436)

- 레포트 **기초보고서 >매출매입현황** 에서 배달매출이 포함된 내역을 확인 가능합니다.

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A9d4ecf6f-3674-4953-9ee1-4188626abda4%3A%EB%B0%B0%EB%8B%AC_%EB%A7%A4%EC%9E%85%EB%A7%A4%EC%B6%9C%ED%98%84%ED%99%A9.png&blockId=21fe8268-560a-8183-a995-ccce6d5c1bd8)

### FAQ

**같은 저희 가게인데 왜 매장명이 다르게 나오나요?**

매장명은 혜움레포트 등록 사업자명이 아닌 배달앱에 등록된 가게 이름을 기준으로 합니다. 배달의 민족을 예시로 들면 [가게정보·원산지] 페이지에 표시된 [상호명] 이 기준입니다.

**고객의 주문 취소건은 어떻게 반영되나요?**

주문일로 부터 5일 이내 취소 완료될 경우, 내역 업데이트시 주문건 취소가 반영됩니다.
