- 사용자는 원하는 기간 단위를 선택하여, 보고서를 조회할 수 있습니다.
  - [단위 : 일] 일 별 데이터 조회 가능하며, 조회 기간은 [7일/30일/직접 선택] 선택 가능
    - 7일 : 오늘로부터 과거 7일
    - 30일 : 오늘로부터 과거 30일
    - 직접 선택 : 선택 기간 제한(1~31일), 2022년 1월부터 선택 가능
  - [단위 : 월] 월별 데이터 조회 가능하며, 조회 기간은 [올해/3개월/6개월] 선택 가능
    - 올해 : 올해 1월~12월
    - 3개월 : 이번 달 포함 과거 3개월
    - 6개월 : 이번 달 포함 과거 6개월
    - 12개월 : 이번 달 포함 과거 12개월
  - [단위 : 분기] 분기 별 데이터 조회 가능하며, 조회 기간은 [올해/3년] 선택 가능
    - 올해 : 올해 1Q~4Q
    - 3년 : 재작년-올해 1Q~4Q
  - [단위 : 년] 년별 데이터 조회 가능하며, 조회 기간은 [3년/5년] 선택 가능
    - 3년 : 이번 년도 포함 과거 3년
    - 5년 : 이번 년도 포함 과거 5년

### FAQ

- **보고서는 어떤 데이터로 생성이 되나요?**
  사용자가 직접 레포트에 연동한 외부 기관(홈택스, 여신금융협회, 카드사)으로부터 받아온 거래 내역을 바탕으로 보고서가 생성됩니다.

  참고 : [레포트 기관연동 기능안내레포트 기관연동 기능안내](https://helpdesk.heumtax.com/12ee8268-560a-807e-9847-c1c2b11f00ee)

- **보고서는 언제 업데이트 되나요?**
  거래조회 메뉴 매출.매입에 연동된 데이터를 실시간으로 반영합니다. 단 매출, 매입 연동 데이터는 보통 일 1회 업데이트 됩니다.

- **보고서의 원본 데이터를 보고 싶어요!**
  매출/매입 보고서를 구성하는 거래 데이터들은 레포트의 [거래조회 > 매입/매출 거래] 메뉴에서 확인할 수 있으며, ‘엑셀 다운로드’를 통해 자유롭게 조회/분석할 수도 있습니다.

- **기장 수임을 해야 보고서를 볼 수 있나요?**
  혜움 레포트에 가입한 사용자라면, 누구나 매출/매입 현황 보고서를 조회할 수 있습니다.
