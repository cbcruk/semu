# 사용자 권한 관리

> 원문: https://support.alfred.kr/22ae8268-560a-809a-a2ce-f2fa69d1c03d

> **새로운 권한 관리 체계는?**
>
> - 관리자가 권한을 생성하고 사용자에게 부여하는 방식의 권한 관리가 이루어집니다
  (회사에서 직무와 직무에 따른 업무 범위를 만들고 직원에게 부여하는 것과 유사)
>
> - 권한에 따라 접근 가능한 메뉴를 설정 할 수 있습니다
>
> - 1명의 사용자가 여러 권한을 가질 수도 있습니다

### 사용자 관리 바로 가기

[알프레드 - 올인원 금융 SaaS 경리부터 급여, 세무까지 이제, 알프레드 하나로 해결하세요 https://app.alfred.kr/settings/user](https://app.alfred.kr/settings/user)

### 신규 권한 생성하기 & 권한 부여하기 (일반 사용자)권한 신규 생성하기

[https://app.guideflow.com/embed/qkqmvd1c4p](https://app.guideflow.com/embed/qkqmvd1c4p)

1. **사용자 권한 관리** 페이지 우측 상단 **권한 그룹 관리** 클릭
1. **+** 모양의 추가 버튼을 클릭
1. 권한 명 입력
1. **해당 권한으로 접근 가능한 메뉴 선택** 후 저장

#### 권한 부여/수정 하기

1. **사용자 우측의 수정 버튼** 클릭

  ![](../../../../images/29da9fb7ee36f7d1c77c.png)

1. 부여/수정할 사용자 권한 선택 후 수정 버튼을 눌러 저장

#### 권한 삭제하기

1. **사용자 권한 관리** 페이지 우측 상단 **권한 그룹 관리** 클릭
1. 삭제할 권한을 클릭
1. 클릭시 나타나는 X 버튼 클릭

  ![](../../../../images/895ed71cbcf8079e3875.png)

1. 안내 메세지 확인 후 삭제 클릭

### 권한 유형

**관리자**

- 관리자는 모든 메뉴에 접근 할 수 있으며 모든 사용자에게 권한을 부여/회수 할 수 있습니다 
  (다른 관리자 포함)

- 회사 계정 관리자, 대표자 등이 보통 관리자 권한을 가집니다

**일반 사용자**

- 관리자 권한이 아닌 설정된 특정 권한을 부여 받은 사용자 입니다.

| 유형 | 접근 가능 기능 | 권한 생성/부여/삭제 | 사용자 초대 |
| --- | --- | --- | --- |
| **일반 사용자** | 부여된 기능 | X | X |
| **관리자** | 전체 | O | O |

### 세무 수임 고객의 권한 관리 안내

- 관리자는 세무 메뉴를 포함한 모든 메뉴에 접근 할 수 있습니다
- 세무 메뉴에 대한 별도 접근 권한이 필요한 경우, 새로운 사용자 권한을 생성해야 합니다.
  (권한 그룹관리 버튼 클릭 후 아래 예시처럼 세무, 인사 등 세무업무 관련 메뉴 접근 가능한 권한 신규생성)
