### 인건비현황 보고서 업데이트 안내

- 인건비현황 보고서는 기장 담당자의 급여카드 계산 완료시 업데이트 됩니다.

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F54720636-34a8-4aa9-9b58-588d29306c22%2Fd4024b40-6b02-4a5c-b514-7c9621c6c89f%2FGroup_10777.png&blockId=21fe8268-560a-81e4-b29e-c9ce46a54736)

- 단 **급여계산 완료 후 재계산**하는 경우 보고서는 일시적으로 업데이트 이전 상태로 되돌려집니다.
  - 재계산 이후 다시 급여카드 계산 완료 시 재 계산된 내용으로 보고서에 반영됩니다.
- **추가 급여카드를 생성하는 경우**  추가 급여카드 계산 완료 시 해당 내역이 보고서에 반영됩니다.

  예시. 급여카드를 재계산 하는 경우

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F54720636-34a8-4aa9-9b58-588d29306c22%2Fd48520f1-b3a3-47a1-aef9-1d6653781f39%2FFrame_2609370.png&blockId=21fe8268-560a-81df-8bc2-c94fda718f83)

### FAQ

- **인건비현황 보고서는 언제 업데이트 되나요?**
  혜움의 급여 시스템을 사용하시는 경우에 아래의 작업이 완료되면 자사의 인건비 보고서를 확인 할 수 있게 됩니다.

  - 급여카드 생성 후 계산 완료
    - 계산 완료를 위해 고객님은 해당 월 급여 내역을 입력해 주셔야 합니다.
    - 급여내역 입력 후 기장 담당자가 계산 및 내용을 확정하면 계산 완료가 됩니다.
- **다른 곳에서 기장을 하다가 혜움으로 옮겼는데  수임 이전 데이터도 확인 가능한가요?**
  아쉽게도 확인이 어렵습니다. 인건비현황 보고서는 혜움 급여 시스템 데이터를 기반으로 하므로, 처음 급여 내역(월별 급여카드) 계산 완료된 월 부터의 데이터를 확인하실 수 있습니다.

또한 재직자 수 추이의 연평균 인원도 기장 수임 이전의 직원 데이터는 반영되지 않으므로 실제 연평균 재직자 수와 차이가 있을 수 있습니다.

- **이번달 중간에 입사자/퇴사자가 발생하면 보고서에는 어떻게 반영되나요?**
  입사/퇴사가 발생한 월을 기준으로 반영됩니다. 단 월 말일까지 근무한 퇴사자는 해당 월의 재직자에 포함됩니다.

  - **12.21 퇴사 = 12월 퇴사자로 집계 & 12월 재직자 미집계**
  - **12.31 퇴사 = 12월 재직자로 집계**
  - 입사취소 : 등록된 직원 삭제 후 레포트 페이지 새로 고침시 반영
- **근로, 사업, 일용. 기타소득은 어떻게 구분되나요?**
  급여를 지급받는 대상에게 급여가 어떤 방식으로 제공되었는지에 따른 구분입니다.

  - **근로소득** : 정규직/계약직 으로 회사 소속의 근로 계약을 맺고 급여를 지급 받는 형태
  - **사업소득** : 회사 근로자로 소속되지 않으면서 정기적으로 급여를 지급 받는 형태
  (ex. 학원과 계약하여 직원이 아니나 정기적으로 급여를 지급 받는 강사)

  - **일용소득** : 일용직 근로자로 계약하여 급여를 지급 받는 형태
  - **기타소득** : 근로, 사업, 일용 소득에 속하지 않으며 일시적으로 급여(사례)를 제공 받은 형태
  (ex. 강연료, 사례금, 심사료와 같이 일시적 용역을 제공하는 형태)
