# 나이스페이먼츠

> 원문: https://support.alfred.kr/21fe8268-560a-81b8-9868-ed2cbe539b50

> **필요정보**
>
> - **상점아이디 (MID)**
  나이스페이 어드민 > 가맹점정보 > 기본정보 상단에서 확인 가능
>
> - **merchantKey**
>
> - **나이스페이먼츠 상점관리자 로그인 ID (userid)**
>
> - **나이스페이에 IP등록 요청 (필수)**

#### 상점아이디 (MID) 확인하기

- 나이스페이 상점 관리자 로그인 합니다 ([바로가기](https://npg.nicepay.co.kr/))
- 가맹점 정보 > 기본정보 메뉴에서 ‘**기본정보**’ 영역 아래 선택창에서 MID를 확인 할 수 있습니다.

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A25bed851-a0c2-42b1-a855-ee14c0a52f4b%3AGroup_10819.png&blockId=21fe8268-560a-8186-b44b-f1fb71ee2f83)

  - ex) [nicepay01m : 나이스페이] 와 같이 되어 있다면 앞부분의 ‘nicepay01m’가 MID 입니다

#### merchantKey 확인하기

- 나이스페이먼츠 상점 관리자 로그인 후
- 가맹점 정보 > KEY 확인 메뉴에서 확인 가능합니다.

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A19447328-34c6-481c-b0b5-fe8948f652b7%3AFrame_121321472.png&blockId=21fe8268-560a-8157-a79f-ffb6ae639cf8)

- 아래 내용을 나이스페이측에 메일로 전달 후 등록 완료시 연동 가능합니다.

  > - 제목: 대사 IP 등록 요청 문의
