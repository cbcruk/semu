# 토스페이 (간편결제)

> 원문: https://support.alfred.kr/21fe8268-560a-812e-846b-dedb971b6c73

> **필요정보**
>
> - **API key**
>
> - **상점아이디 (MID)**

1. **토스페이 파트너스에 로그인합니다.** 
  [https://tosspay.toss.im/partners/auth/login](https://tosspay.toss.im/partners/auth/login)

1. **가맹점 정보 > API Key 를 확인하여 복사합니다.**

  ![](../../../images/ffaeac96423603753254.png)

1. **토스페이(간편결제) 연동창에서 상점아이디 (MID) 및 복사한 API Key를 입력합니다.**

  ![](../../../images/15dc68047636e9a47058.png)
