# PG연동 사전 준비 (연동키 확인)

> 원문: https://support.alfred.kr/21fe8268-560a-8109-8b4b-e5470dfed06f

> PG사 연동을 위해서는 상점아이디 (MID) 및 연동키가 필요합니다. 연동키는
>
> - 온라인(어드민)에서 연동키를 확인할 수 있는 경우
>
> - 고객센터로 문의해야 하는 경우
>
> 두 가지 경우가 있어 사용하시는 PG사에 해당되는 방법으로 연동키를 받으셔야 합니다.
