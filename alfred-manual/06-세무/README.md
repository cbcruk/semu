# 세무

> 원문: https://support.alfred.kr/399e8268-560a-81de-960c-df7d6a131aac

> **세무**에서는 부가세·법인세·원천세·연말정산 등 각종 세무 신고에 필요한 자료를 확인하고 제출할 수 있습니다. 세무 구독 고객에게 제공됩니다.

**이 섹션에서 할 수 있는 일**

- 세목별 신고 일정과 제출 자료 확인
- 신고에 필요한 자료 제출
- 신고 진행 현황 확인

**노출 대상:** 세무 구독 고객

> 사업자 유형에 따라 법인세(법인사업자) 또는 종합소득세(개인사업자)가 노출됩니다.
