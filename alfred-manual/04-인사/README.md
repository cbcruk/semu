# 인사

> 원문: https://support.alfred.kr/399e8268-560a-81d6-9d10-c829155ad3e4

> **인사**에서는 회사 구성원 정보를 관리하고, 전자서명과 제증명 발급 등 인사 관련 업무를 처리할 수 있습니다.

**이 섹션에서 할 수 있는 일**

- 구성원 정보 등록 및 관리
- 전자서명 요청 및 관리
- 각종 증명서 직접 발급

**노출 대상:** 전체 (일부 메뉴는 급여 구독)
