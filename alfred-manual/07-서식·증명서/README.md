# 서식·증명서

> 원문: https://support.alfred.kr/399e8268-560a-8180-bf02-fe337e73658b

> **서식·증명서**에서는 사업 운영에 필요한 무료 서식을 내려받고, 세무 관련 증명서를 온라인으로 발급받을 수 있습니다.

**이 섹션에서 할 수 있는 일**

- 사업 운영에 필요한 무료 서식 다운로드
- 결산·부가세·원천세 관련 증명서 및 사업자 기초 서류 발급

**노출 대상:** 전체 (증명서 발급 일부는 세무 구독)
