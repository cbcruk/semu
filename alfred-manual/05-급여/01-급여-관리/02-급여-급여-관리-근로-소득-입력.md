# [급여] 급여 관리 - 근로 소득 입력

> 원문: https://support.alfred.kr/39de8268-560a-8043-8f9a-f43502c04146

## FAQ

---

#### 급여를 입력(or제외) 해야하는 직원이 리스트에 없어요.

- 직원관리 버튼을 통해서 <직원관리> 메뉴로 이동. 추가 혹은 제외해야할 직원을 수정 시 반영됩니다.
- 아래 `새로고침` 버튼을 통해서 입사자/퇴사자 직원 리스트를 최신화 할 수 있습니다.

![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Ff60b8fe0-0819-4271-b210-36ef2fa3df03%2FUntitled.png&blockId=39de8268-560a-80cf-91d2-c498d16a9002)

#### 중도 입사자(or 중도 퇴사자)의 기본급의 일할계산이 필요해요.

- 일할계산 필드에 **요청 체크박스를 선택**하면 계산 시 일할계산으로 처리됩니다.
- 이미지 보기(클릭)

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fe2030804-9b00-400a-95ad-52fb3b75c9b3%2FUntitled.png&blockId=39de8268-560a-80e7-8a0b-dda749984081)

#### 추가 급여카드를 생성했는데 근로 소득이 입력되지 않아요.

- 추가 급여카드에서는 근로소득 입력이 불가합니다. 매월 자동으로 생성되는 기본 급여카드에서만 입력이 가능합니다.
- 근로 소득입력이 필요하다면, 담당자에게 계산중 혹은 완료된 급여카드 해제를 요청하셔야 합니다.

#### 수당을 어떻게 추가 할 수 있나요?

- 직원의 수당의 경우 <직원관리>메뉴에서
- 과세 수당의 추가
  - 수당관리 버튼을 선택 시, 수당 추가가 가능한 팝업이 노출됩니다.

  ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fb761d9c4-38e6-4add-801e-3794f92b4426%2FUntitled.png&blockId=39de8268-560a-80cb-81b5-de5f73e00529)

  - +**수당추가** 버튼을 선택 > 수당 유형 **과세** 선택 > 과세 수당명을 입력 후 > 확인 버튼을 선택하면 팝업이 닫히고 적용됩니다.
  - 과세 수당 추가 예시 보기(클릭)

    ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fad6c7de7-0c5e-4d41-8d66-2915e84affb9%2FUntitled.png&blockId=39de8268-560a-8032-9ad0-f28bcd6c4de6)

    ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F57dc8eca-0e7b-48ce-bd38-0b429af24965%2FUntitled.png&blockId=39de8268-560a-805d-a95b-f6329b1b5e89)

- 비과세 수당의 추가
  - 위와 동일하게 수당추가 뒤, 수당 유형을 비과세 선택. 비과세 유형을 선택합니다.
  - 비과세 유형은 지정되어 있으며, 최대 입력 가능한 금액이 제한되어 있습니다.
  - 비과세 수당 추가 예시 보기(클릭)

    ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F621ecbe7-c77c-437a-a086-d5bc186af3f9%2FUntitled.png&blockId=39de8268-560a-8058-a027-e3d37f699ee4)

#### 기타 공제금 관리는 무엇인가요?

- 기타 공제금은 회사의 급여 정책에 따라서 급여에서 공제되는 금액으로,  주로 선지급금(가불금)이나 사내 동호회비와 같은 항목 등이 있습니다.
- 연말정산 공제항목(소득세, 농특세)는 기장 담당자가 입력하니 입력하시지 않으셔도 됩니다.

## 근로 소득 입력하기

---

1. `입력가능` 상태의 **기본 급여카드**를 선택합니다.

![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F691c3d62-f1f2-4ac1-9ebb-6c3b3c63dcdd%2FUntitled.png&blockId=39de8268-560a-80f4-85c9-cff1fc3f4e18)

2. 근로 탭을 선택 후 근로자별 **기본급**, **과세수당**, **비과세수당 등**을 항목을 **입력**합니다.

- 0은 기본 값입니다. 0으로 입력된 값은 계산에 반영되지 않습니다.
- 과세, 비과세수당 추가는 `수당관리` 버튼 선택 후 설정하여 입력 가능합니다.
- 공제금 입력 필요 시, `기타공제금 관리`버튼 선택 후 설정하여 입력 가능합니다.

![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Ff43bbd89-9d54-41c1-ad1e-8956c3d742bf%2FUntitled.png&blockId=39de8268-560a-80b3-b8ee-d0e781d0cf85)

3. 입련된 내용을 확인 후 `계산 요청` 버튼을 선택하면 확인 팝업이 노출됩니다. 팝업에서 안내되는 내용을 확인 후 `계산 요청` 버튼을 선택합니다.

- 임시 저장이 필요하시다면 임시 저장 버튼을 선택하시면 됩니다.

![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fe1feeb73-4ae2-4f76-a940-acd476dbe632%2FUntitled.png&blockId=39de8268-560a-807d-923f-c17f9d25043f)

4. **계산 요청 상태**로 변경되며, <급여관리> 메뉴 선택 시 해당 급여카드가 `계산중` 상태로 변경된 것을 확인할 수 있습니다.

![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F2af012c9-f385-4650-a699-fed0125ab78a%2FUntitled.png&blockId=39de8268-560a-8010-b1ef-fe042edc252b)
