# 급여 관리

> 원문: https://support.alfred.kr/59be8268-560a-82cc-9353-817583df53f8

> **급여 관리**에서는 매월 자동으로 생성된 급여 카드를 확인해 계산을 요청하고, 담당자가 계산을 완료하면 급여명세서를 작성해 근로자에게 발송할 수 있습니다. 기존에 '세무 > 인사 > 급여관리'에 있던 기능이 이번 개편으로 '급여' 카테고리로 이동했습니다.

**이 메뉴에서 할 수 있는 일**

- 매월 자동 생성된 급여 카드(급여대장) 확인
- 대상자·근태·지급/공제 항목 확인 및 변동 사항 반영
- 담당자에게 급여 계산 요청
- 계산 완료된 급여대장 확인 및 급여 지급
- 급여명세서 계산식 입력 및 근로자 발송

**경로:** 급여 > 급여 관리

**노출 대상:** 세무 구독 고객

> 급여 구독 고객에게는 이 메뉴 대신 신규 메뉴인 '급여 정산'이 노출됩니다. 급여 관리는 향후 급여 정산으로 통합될 예정입니다.

---

### 급여 처리 흐름 한눈에 보기

급여 관리는 다음 흐름으로 진행됩니다. 회색으로 표시된 단계는 담당자가 처리하는 단계입니다.

**① 급여 카드 확인 → ② 내용 확인·변동 반영 → ③ 계산 요청 → (담당자 계산·확정·ERP 입력) → ④ 계산 완료 확인 → ⑤ 급여 지급 → ⑥ 급여명세서 관리·발송**

미리 설정해둔 급여 시스템 설정에 따라 **매월 기본 급여 카드가 자동으로 생성**됩니다. 고객은 생성된 카드를 확인하고 변동 사항만 반영한 뒤 계산을 요청하며, 실제 급여 계산과 확정은 담당자가 진행합니다.

### 1단계. 급여 카드 확인

#### 1) 급여대장 선택

급여 관리 메뉴에서 처리할 **귀속월**을 확인하고 해당 급여대장을 선택합니다. 설정에 따라 자동 생성된 급여 카드를 확인할 수 있습니다.

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F2d0623e5-1853-4539-b7e7-80ee8a96ff2c%2FUntitled.png&blockId=39de8268-560a-80b2-89fd-c77b21cd0813)

#### 2) 대상자 확인

급여대장에는 임금 지급 시기를 기준으로 대상자가 **자동으로 반영**되어 있습니다. 소득 유형에 따라 반영 방식이 다릅니다.

| 소득 유형 | 대상자 반영 방식 |
| --- | --- |
| 근로소득(월급·일급·시급) | 등록된 구성원 정보를 자동으로 조회하여 반영 |
| 일용·사업·기타소득 | 급여대장에서 `대상자 추가` 기능으로 정보를 직접 입력 |

중도 입·퇴사자나 수습기간 대상자 등 재직 상태에 특이사항이 있는 구성원은 지급 항목이 자동으로 계산됩니다. 각 항목의 `fx` 아이콘을 클릭하면 적용된 계산식을 확인할 수 있으니, 계산식의 정확성과 오류 여부를 한 번 더 검토해 주세요.

---

### 2단계. 내용 확인 및 변동 사항 반영

자동 생성된 급여 내용을 확인하고, 이번 달에 변동이 있으면 반영합니다.
작성 중인 급여카드는 임시저장이 가능합니다.

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A342ace9b-f126-4999-a966-8137ea3052e2%3Aimage.png&blockId=39de8268-560a-801d-b16c-cce0b2dcaf6d)

#### 근태 입력

연장·야간·휴일근로 등 계약 시간 외 근무가 발생하거나 지각·조퇴·결근 등 근태 변동이 있는 경우, 근태(시간)를 입력해 반영합니다. 근태 변동으로 지급액이 바뀌면 `fx` 아이콘으로 변경된 계산식을 확인할 수 있습니다.

- 근태 기반 공제 항목은 **시간 단위**로 입력합니다.
- 주휴공제는 예외적으로 **일 단위**로 입력하며, 소정 근로시간 항목에 일 주휴시간을 추가로 입력합니다.

#### 항목 설정

지급·공제에 설정된 항목 중 이번 달에 사용하지 않는 항목은 체크를 해제해 제외할 수 있습니다. 단, 새로운 항목을 추가하려면 급여 설정 메뉴에서 진행해야 합니다.

#### 구성원 정보 변경이 필요할 때

급여대장 생성 후 구성원 정보나 임금에 변동이 생긴 경우, 화면 하단 메뉴로 조정할 수 있습니다.

| 메뉴 | 기능 설명 |
| --- | --- |
| 구성원 정보 동기화 | 업데이트된 구성원 정보 기준으로 동기화 (근태·지급·공제 정보는 기존 데이터 유지) |
| 공제액 계산 | 입력한 지급 정보를 바탕으로 공제액 자동 계산 |
| 정산 초기화 | 지급액·공제액을 초기 계산값으로 되돌림 (수동 수정 내역 모두 초기화) |
| 대상자 삭제 | 해당 급여대장의 지급 대상이 아닌 구성원을 선택해 삭제 |

### 3단계. 계산 요청

급여 내용 확인과 변동 반영이 끝나면 `계산 요청` 버튼을 누릅니다. 근로·일용·사업·기타 소득을 **모두 입력한 후** 요청해 주세요.

>

계산 요청 이후에는 담당자가 급여 계산과 확정을 진행합니다. (담당자 처리 단계)

---

### 4단계. 계산 완료 확인 및 급여 지급

담당자의 계산이 완료되면 해당 급여대장을 선택해 상세 내역을 확인합니다.

- 계산이 완료된 급여대장은 `완료` 태그로 확인할 수 있습니다.
- 각 구성원의 **차인지급액**(공제 후 실지급액)을 확인한 뒤 급여를 지급합니다.
- 급여 화면 상단의 **특이사항** 항목에서 담당자가 해당 월에 남긴 주요 이슈를 확인할 수 있습니다.

> ![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A9dd1df6c-d86a-444d-a586-08e5831f2107%3A46d43da2-68de-465d-b7a9-c8280e9ba25d.png&blockId=39de8268-560a-8004-a00c-ec9f5c65a2a2)

급여대장에서 근로 탭의 `급여명세서 관리` 버튼을 선택합니다. 각 근로자의 수당 항목에 계산식 입력란이 나타나며, 수당 산출 방법을 텍스트로 입력합니다. (예: `16시간 × 17,000원 × 1.5`) 근로기준법 개정에 따라 급여명세서에 필수로 기재해야 하는 사항을 입력하는 단계입니다.

#### 2) 발송 대상 선택 및 발송

입력을 완료하면 발송할 대상을 선택하고 `급여 명세서 발송` 버튼을 누릅니다.

- 받는 분의 **이메일은 필수 입력** 항목입니다.
- `미리보기`로 발송될 명세서를 확인할 수 있습니다.
- 명세서는 발송 후에도 재발송할 수 있습니다.

### FAQ. 자주 묻는 질문

**급여 카드는 직접 만들어야 하나요?**

아니요. 미리 설정해둔 급여 시스템 설정에 따라 매월 기본 급여 카드가 자동으로 생성됩니다. 생성된 카드를 확인하고 계산을 요청하면 됩니다.

**계산 요청 후 급여를 수정할 수 있나요?**

계산 요청 후에는 담당자가 계산을 진행하므로 직접 수정할 수 없습니다. 수정이 필요하면 담당자에게 요청해 주세요.

**차인지급액이 무엇인가요?**

지급액에서 4대보험·세금 등 공제액을 뺀, 근로자에게 실제로 지급되는 금액입니다.

**중도 입·퇴사자의 급여는 어떻게 되나요?**

구성원 정보에 등록된 입·퇴사일을 기준으로 지급 항목이 자동 계산됩니다. `fx` 아이콘으로 적용된 계산식을 확인하고 검토해 주세요.

**일용·사업·기타 소득자에게도 급여명세서가 발송되나요?**

현재 이메일 발송은 근로 소득자에게만 제공됩니다. 일용·사업·기타 소득자는 급여대장·명세서를 다운로드해 전달하면 됩니다.

**급여명세서 관리란 무엇인가요?**

근로기준법 개정에 따라 급여명세서 필수 기재 사항(수당 산출 계산식 등)을 입력할 수 있도록 돕는 기능입니다.

**입력되지 않은 소득 유형 안내 문구가 발생해요.**
근로, 일용, 사업, 기타 소득 유형 중에 입력되지 않은 항목이 있다면 우측과 같이 안내문이 먼저 노출됩니다. 해당 사항이 없다면 바로 계산 요청하시면 됩니다.
