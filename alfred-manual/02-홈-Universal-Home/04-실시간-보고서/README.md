# 실시간 보고서

> 원문: https://support.alfred.kr/399e8268-560a-8132-b8ad-dee4b3bf372a

> **실시간 보고**서에서는 매일 업데이트되는 자금·손익·세금 정보를 한눈에 확인할 수 있습니다. 
연동한 계좌와 증빙 데이터를 기반으로 우리 사업의 현재 상태를 실시간으로 보여줍니다.

**이 섹션에서 할 수 있는 일**

- 자금 흐름과 잔액 실시간 확인
- 이번 달 손익(매출·비용·순이익) 확인
- 다가오는 부가세 예상액 미리 확인

**노출 대상:** 전체 (구독 무관)

> 실시간 보고서의 항목은 **1. 연동된 기관으로부터 내역 수집** → **2. 계정 과목 분류 완료** 된 경우에만 조회됩니다. 
데이터가 확인되지 않을 경우, 위의 순서대로 데이터 집계가 가능한 상태인지 확인해 주세요.
