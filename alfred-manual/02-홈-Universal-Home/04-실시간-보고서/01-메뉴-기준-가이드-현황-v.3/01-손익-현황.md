# 손익 현황

> 원문: https://support.alfred.kr/b26e8268-560a-83af-ab91-01fdec27bcfe

> **손익 현황**에서는 우리 사업의 손익과 매출·매입 내역을 실시간으로 확인할 수 있습니다. 이번 개편으로 기존에 별도였던 매출·매입 보고서가 이 화면 안의 탭으로 통합되었습니다.

**이 메뉴에서 할 수 있는 일**

- 기간별 손익 현황 확인
- 매출·매입 내역을 세금계산서·신용카드·현금영수증·PG/쇼핑몰별로 확인
- 매출·매입 데이터 기반 예상 손익 확인

**경로:** 실시간 보고서 > 손익 현황

**노출 대상:** 전체 (구독 무관)

---

### 화면 구성

손익 현황은 두 개의 탭으로 이루어져 있습니다.

![](https://oopy.lazyrockets.com/api/v2/notion/image?src=attachment%3A9c689b78-36de-4186-9145-073e569aa1cd%3AGroup_1000004397.png&blockId=399e8268-560a-803f-b290-e3eb31e8dc70)

#### 손익 탭

사업의 손익 현황을 한눈에 확인합니다.

#### 매출·매입 탭

기존의 매출/매입 현황 보고서가 이 탭으로 들어왔습니다. 세 가지 영역으로 구성됩니다.

- **매출·매입 요약** : 기간별 매출·매입 및 손익 현황 요약
- **매출·매입 상세** : 세금계산서, 신용카드, 현금영수증, PG/쇼핑몰별 매출·매입 내역
- **예상 손익 상세** : 매출·매입 데이터를 바탕으로 산출한 예상 손익

---

### 조회 기간 선택

원하는 기간 단위를 선택해 조회할 수 있습니다.

- **일** : 7일 / 30일 / 직접 선택 (1~31일 범위)
- **월** : 올해 / 3개월 / 6개월 / 12개월
- **분기** : 올해 / 3년
- **년** : 3년 / 5년

---

### FAQ. 자주 묻는 질문

**보고서는 어떤 데이터로 생성되나요?**

연동한 외부 기관(홈택스, 여신금융협회, 카드사 등)에서 받아온 거래 내역을 바탕으로 생성됩니다.

**보고서는 언제 업데이트되나요?**

연동된 매출·매입 데이터를 실시간으로 반영하며, 연동 데이터는 보통 하루 1회 업데이트됩니다.

**원본 거래 데이터는 어디서 보나요?**

경리 > 매출 증빙 관리 / 매입 증빙 관리에서 개별 거래 내역을 확인할 수 있습니다.

**구독하지 않아도 볼 수 있나요?**

네. 손익 현황은 모든 사용자가 조회할 수 있습니다.
