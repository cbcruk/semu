# 경리

> 원문: https://support.alfred.kr/399e8268-560a-81fb-8a16-f117432bb8ab

> **경리**에서는 매출·매입 증빙 관리부터 입출금·계좌 확인, 세금계산서 발급과 세금 납부까지 일상적인 경리 업무를 처리할 수 있습니다.

**이 섹션에서 할 수 있는 일**

- 매출·매입 증빙 확인 및 분류
- 은행 계좌 거래 내역과 잔액 확인
- 거래처 관리
- 세금계산서 발급
- 세금 조회 및 납부

**노출 대상:** 전체 (구독 무관)
