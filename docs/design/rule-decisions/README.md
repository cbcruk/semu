현행 클라이언트 규칙의 열린 질문에 대한 서버 결정입니다. 근거 자료는 [규칙 문서](../../reference/rules/README.md)와 픽스처(`apps/api/test/fixtures/rules/`), 이 폴더 위의 재설계 문서입니다. 컨텍스트마다 파일 하나를 둡니다.

## 읽는 법

- **따름:** 현행 동작을 서버가 그대로 재현합니다. 해당 픽스처 케이스를 그대로 서버 테스트로 씁니다
- **바꿈:** 현행이 버그이거나 화면마다 달라서 서버가 다르게 동작합니다. 영향받는 케이스는 각 규칙의 **바뀌는 케이스**에 있고, 서버 테스트에서는 기대값을 바꿔 씁니다
- **가정:** 학습용 가정입니다. 내부 자료(약관·메뉴 코드, 계약서, 현행 화면 데이터)나 외부 서비스의 실제 동작(수집 업체, 인증서 발급기관, 메신저 브리지, 홈택스 발급)이 있어야 정할 수 있어 이 저장소에서는 확인할 수 없는 질문입니다. 현행 동작을 두거나 더 안전하거나 단순한 쪽을 골라 결정으로 두고, 근거 칸에 "학습용 가정"과 이유를 적습니다. 해당 케이스는 결정한 기대값으로 서버 테스트에 옮깁니다. 공개 원문으로 확인하려 했으나 찾지 못한 값(예: 예술인 필요경비 고시)도 여기에 둡니다
- **보류:** 외부 사실을 확인해야 정할 수 있어 현행 동작을 임시 결정으로 둔 질문입니다. 2026-11-07에 모두 정해 지금은 없습니다. 공개 원문으로 정한 것은 따름·바꿈으로, 내부·외부 자료가 필요한 것은 가정으로 옮겼습니다
- **임시:** 새 입력이 필요한 설계 문제는 결정에 "(임시)"를 붙여 현행 동작을 두고, 권장 설계를 그 컨텍스트 설계 문서의 열린 질문에 적습니다. 따름·바꿈으로 셉니다
- 질문 번호는 픽스처 `openQuestions` 순서입니다
