# 근로소득 비과세 한도

## 요약

비과세 유형(식대, 자가운전보조금, 보육수당, 연구보조비 등)은 월 한도까지만 비과세이고 넘는 금액은 과세 급여에 더합니다. 회사가 설정에서 한도를 따로 정하면 법정 한도와 작은 쪽을 씁니다. 같은 유형의 여러 항목은 한도를 나눠 씁니다.

## 현행 위치

- 화면: 급여 설정 > 지급 항목의 "비과세 한도 설정", 근로 행의 비과세 열
- 매뉴얼: "비과세 유형은 지정되어 있으며 최대 입력 가능 금액이 제한"
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/non-taxable.ts`

## 로직

```
한도 = min(법정 월 한도, 회사 한도)    // 회사 한도가 없으면 법정 한도
비과세 = min(항목 금액, 남은 한도)
과세 = 항목 금액 − 비과세
한도를 넘으면 NON_TAXABLE_LIMIT_EXCEEDED 경고
```

## 근거

- 스펙 4.6(`docs/reference/spec/payroll.md:411-426`): "한도를 넘는 금액은 과세로 바꾼다", "회사가 설정에서 넣는 `non_taxable_limit_amount`와 법정 한도 중 **작은 값**을 쓴다(추정)"
- 매뉴얼 `alfred-manual/05-급여/01-급여-관리/02-급여-급여-관리-근로-소득-입력.md:45`: 비과세 유형별 최대 입력 금액 제한
- 매뉴얼 `alfred-manual/08-설정/03-급여-설정.md:273-275`: "비과세·연차수당 항목은 세무사랑 코드 연동과 계산식 연결을 위해 반드시 표준 항목명을 사용해야 합니다"
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:206-231`)

## 서버 이전 시 주의

- 한도는 모두 원문으로 확인했습니다. 다만 보육수당은 2026년 조문이 "해당 자녀 1명당" 월 20만원이고, 엔진은 행마다 한도 하나(20만원)를 씁니다. 6세 이하 자녀가 둘 이상이면 한도를 적게 잡습니다. 자녀 수를 행 입력으로 받을지는 열린 질문입니다
- 생산직 야간근로수당은 월정액급여 260만원 이하·직전 과세기간 총급여 3,700만원 이하 요건(시행령 제17조제1항)이 있고, 이 판정은 엔진 밖입니다
- 연 한도 유형은 올해 이미 쓴 금액(`annualNonTaxableUsed`)이 필요합니다. 지금은 행 입력이 주지 않으면 0으로 봅니다
- 화면이 한도를 막지 않고 경고만 하는지, 입력을 막는지는 서버가 정하지 않습니다. 서버는 저장하고 경고합니다
