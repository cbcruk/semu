# 기타소득 원천징수

## 요약

기타소득은 지급액에서 필요경비(지급사유별 의제 경비율 또는 실제 경비)를 뺀 기타소득금액에 20%를 곱합니다. 기타소득금액이 5만원 이하면 과세하지 않습니다(과세최저한). 지방소득세는 소득세의 10%입니다.

## 현행 위치

- 화면: 급여 > 기타 소득 탭(지급사유, 지급액, 필요경비)
- 번들: 지급사유 조회 `/api/payroll/other-labor-income-types/?target_date=`, 경비율 조회 `GET /api/tax-rates/necessary-expenses/`. 계산식 없음
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/withholding.ts`, 지급사유 `apps/api/legacy/src/modules/payroll/reference/reference-data.ts:70-84`

## 로직

```
필요경비 = 지급액 × 경비율(60% 의제, 0% 필요경비 없음) 또는 실제 경비
기타소득금액 = 지급액 − 필요경비
기타소득금액 ≤ 50,000이면 0
소득세 = 기타소득금액 × 20%(지급사유별 세율)   → 원 미만 절사
지방소득세 = 소득세 × 10%
```

## 근거

- 스펙 4.5(`docs/reference/spec/payroll.md:398-409`): "필요경비 = 지급액 × 경비율(지급사유별: 60% 의제 / 0% '필요경비 없는 기타소득' / 실제경비)", "과세최저한: 기타소득금액 ≤ 50,000원(건별)이면 과세 안 함", "소득세 = 기타소득금액 × 20%", "연금계좌·공제부금 해지 소득은 15%로 분리과세 … **확인 필요**"
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:421-435`)

## 서버 이전 시 주의

- 지급사유 코드(60·62·63·64·67·75·76·59), 서화·골동품 경비율 80%, 연금해지 세율 15%는 미확인입니다
- 지급사유를 고르지 않으면 `60`(그 밖에 필요경비 있는 기타소득, 60%)을 씁니다. 현행 기본값과 같습니다
- 과세최저한은 행 단위로 판정합니다. 건별 판정이 실제로 지급 건 단위인지 확인이 필요합니다
