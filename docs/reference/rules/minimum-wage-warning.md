# 최저임금 경고

## 요약

근로 행의 최저임금 산입 항목을 소정근로시간으로 나눈 시급이 그해 최저시급보다 낮으면 `BELOW_MINIMUM_WAGE` 경고를 붙입니다. 저장과 상태 전이는 막지 않습니다.

## 현행 위치

- 화면: 급여 설정의 최저임금(읽기 전용) "2026년 최저시급 10,320원, 월 최저임금 2,156,880원"
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/working-time.ts`의 `isBelowMinimumWage`

## 로직

```
산입 시급 = (기본급 + 최저임금 포함 항목) ÷ 월 소정근로시간
산입 시급 < 최저시급(귀속월 기준표)이면 경고
```

## 근거

- 원문 확인(2026-11-05): 고용노동부고시 제2025-47호(2025. 8. 5.) 2026년 적용 최저임금, 시간급 10,320원·월 2,156,880원(209시간). 최저임금위원회 `https://www.minimumwage.go.kr/minWage/policy/decisionMain.do`. 2025년은 10,030원, 2027년은 10,700원입니다
- 스펙 4.7(`docs/reference/spec/payroll.md:434`): "최저임금 검증: (최저시급 포함 항목 합계) ÷ 소정근로시간 ≥ 해당 귀속연도 최저시급. 2026년 최저시급은 **10,320원**, 월 **2,156,880원**(= 10,320 × 209) [화면 3b9f629f]. 위반하면 경고만 하고 차단하지는 않는 것으로 추정한다"
- 스펙 2.9(`:237`): 급여 설정의 최저임금 읽기 전용 표시
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:315-319`)

## 서버 이전 시 주의

- 경고는 대장 상세의 `warnings`에 `rowId`와 함께 모아 보여 줍니다
- 수습 감액(90%)은 근로조건 정보가 없어 반영하지 않습니다
- 경고만 하는지 막는지는 추정입니다
