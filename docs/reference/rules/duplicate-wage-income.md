# 근로소득 중복 방지

## 요약

근로소득은 귀속월의 정기 급여대장에서만 입력합니다. 추가 대장에는 근로 행을 넣을 수 없고, 한 직원은 귀속월마다 근로 행이 하나뿐입니다.

## 현행 위치

- 화면: 추가 급여카드에 근로소득 탭이 없음
- 매뉴얼: 추가 급여카드에서 근로소득 입력 불가
- 서버 판정 위치는 확인하지 못했습니다(스펙 Q17)

## 로직

```
추가 대장에 근로 행 → WAGE_ROW_ON_ADDITIONAL_LEDGER
같은 회사·귀속월·직원의 근로 행이 이미 있음 → WAGE_INCOME_DUPLICATED(그 대장 ID)
```

## 서버 이전 시 주의

- 간이세액은 월 급여 전체로 계산해야 하므로 근로 행이 둘이면 세액이 틀립니다. 서버가 막는 이유입니다
- BPO 화면의 같은 달 대장 두 개가 상여 대장인지 확인이 필요합니다. 상여를 별도 대장으로 지원하려면 간이세액 특례(지급대상기간)가 필요합니다
- 일용·사업·기타 행은 같은 사람이 여러 번 있어도 됩니다
