# 근로소득 간이세액

## 요약

월 과세 급여, 공제대상가족 수, 8~20세 자녀 수로 간이세액표의 월 세액을 구하고, 근로자가 고른 원천징수 비율(80·100·120%)을 곱해 10원 미만을 버립니다. 지방소득세는 소득세의 10%(10원 미만 절사)입니다. 직접 입력과 미적용도 고를 수 있습니다.

## 현행 위치

- 화면: 급여 설정 > 공제 설정의 "근로소득세(간이세액표 / 직접 입력 / 미적용)", 근로 행의 소득세 열
- 번들: 세액표 조회 `GET /api/tax-rates/simple/`만 있고 계산식은 없습니다(스펙 4.2)
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/wage-income-tax.ts`

## 로직

1. 연 환산 총급여 = 월 과세 급여 × 12
2. 근로소득공제 → 인적공제(1인 150만원) → 연금보험료공제 → 특별소득공제 추정식 → 과세표준
3. 기본세율 → 근로소득세액공제(한도 포함) → 연 세액
4. 월 세액 = 연 세액 ÷ 12, 10원 미만 절사. 8~20세 자녀 공제액을 뺍니다(2026. 2월까지 1명 12,500원, 2026. 3월부터 1명 20,830원)
5. 원천징수 세액 = 월 세액 × 비율, 10원 미만 절사
6. 월 1,000만원 초과는 표 대신 산식을 더합니다

간이세액표는 행 폭(예: 300만원대 2만원)마다 한 값이라, 계산 기준 급여를 정하는 전략이 둘입니다.

| 전략 | 기준 급여 | 300만원·1인 |
|---|---|---:|
| `EXACT_FORMULA` | 입력 급여 그대로 | 59,080 |
| `MIDPOINT_FORMULA`(기본) | 행 중간값(3,010,000) | 60,380 |

## 근거

- 스펙 4.2(`docs/reference/spec/payroll.md:367-375`): "입력은 월 과세급여(비과세 제외), 공제대상가족수(본인 포함), 8~20세 자녀 수, 근로자가 선택한 원천징수 비율(80/100/120%)", "**지방소득세는 소득세 × 10%**", "2026년 개정 여부 확인 필요"
- 매뉴얼 `alfred-manual/08-설정/03-급여-설정.md:242`: 간이세액표에 따라 자동 산출 / 직접 입력 / 미적용
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:122-167`). 연 산식 단계값(총급여 3,600만원 → 연 세액 709,000원)까지 맞췄습니다

## 서버 이전 시 주의

- 공식 간이세액표(소득세법 시행령 별표 2)는 300만원·1인에 74,350원으로, 산식 결과(60,380원)와 차이가 큽니다. 공식 표를 기준표에 넣으면 `lookupSimpleTaxTable` 전략으로 바꾸고, 그전까지는 `wageIncomeTax.simpleTaxStrategy`를 미확인으로 표시합니다(D4). 산식 계수는 원문으로 확인했습니다
- 자녀 공제액이 바뀐 2026-03 기준표가 있습니다. 원천세는 지급월 기준표를 쓰므로 2026. 3월 지급분부터 새 공제액입니다
- 비율은 ppm(`withholdingRatePpm`: 800000·1000000·1200000)으로 주고받습니다
- 원천세는 **지급월** 기준표를 씁니다. 귀속월과 지급월 기준표가 다르면 소득세·지방소득세만 지급월 표로 다시 계산합니다
- 중소기업 취업자 감면율은 행 입력(`reduction.ratePpm`)입니다. 청년 90%, 그 외(60세 이상·장애인·경력단절) 70%이고 한도는 과세기간 200만원입니다(조세특례제한법 제30조제1항)
