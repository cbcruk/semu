# 근로소득 간이세액

## 요약

월 과세 급여, 공제대상가족 수, 8~20세 자녀 수로 간이세액표의 월 세액을 구하고, 근로자가 고른 원천징수 비율(80·100·120%)을 곱해 10원 미만을 버립니다. 지방소득세는 소득세의 10%(10원 미만 절사)입니다. 직접 입력과 미적용도 고를 수 있습니다.

## 현행 위치

- 화면: 급여 설정 > 공제 설정의 "근로소득세(간이세액표 / 직접 입력 / 미적용)", 근로 행의 소득세 열
- 번들: 세액표 조회 `GET /api/tax-rates/simple/`만 있고 계산식은 없습니다(스펙 4.2)
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/wage-income-tax.ts`

## 로직

1. 연 환산 총급여 = 월 과세 급여 × 12
2. 근로소득공제 → 인적공제(1인 150만원) → 연금보험료공제 → 특별소득공제 추정식 → 과세표준
3. 기본세율 → 근로소득세액공제(한도 포함) → 연 세액
4. 월 세액 = 연 세액 ÷ 12, 10원 미만 절사. 8~20세 자녀 공제액을 뺍니다(2026. 2월까지 1명 12,500원, 2026. 3월부터 1명 20,830원)
5. 원천징수 세액 = 월 세액 × 비율, 10원 미만 절사
6. 월 1,000만원 초과는 표 대신 산식을 더합니다

위 1~4는 별표 2 제1호가 표를 만든 산식입니다. 원천징수는 **표에 적힌 금액**이 기준이고, 산식으로 다시 계산하면 표와 다릅니다. 그래서 엔진은 공식 표를 찾습니다(2026-11-14, D4).

### 공식 표 찾기 (`OFFICIAL_TABLE`, 기본)

1. 월 과세 급여가 770천원 미만이면 0
2. 10,000천원 미만이면 급여가 든 행(하한 이상, 상한 미만)의 공제대상가족 수 열. 행 폭은 770~1,500천원 5천원, ~3,000천원 1만원, ~10,000천원 2만원으로 646행입니다
3. 정확히 10,000천원이면 10,000천원 행. 넘으면 그 행 값에 제6호 산식을 더하고 10원 미만 절사
   - 14,000천원 이하: + (초과액 × 98% × 35%) + 25,000
   - 28,000천원 이하: + 1,397,000 + (14,000천원 초과액 × 98% × 38%)
   - 30,000천원 이하: + 6,610,600 + (28,000천원 초과액 × 98% × 40%)
   - 45,000천원 이하: + 7,394,600 + (30,000천원 초과액 × 40%)
   - 87,000천원 이하: + 13,394,600 + (45,000천원 초과액 × 42%)
   - 그 초과: + 31,034,600 + (87,000천원 초과액 × 45%)
4. 공제대상가족이 11명을 넘으면 11명 세액 − (10명 세액 − 11명 세액) × 넘는 인원, 0 미만은 0(제4호)
5. 8~20세 자녀 공제액을 빼고 0 미만은 0(제3호), 비율을 곱해 10원 미만 절사

| 전략 | 방법 | 300만원·1인 |
|---|---|---:|
| `OFFICIAL_TABLE`(기본) | 공식 표 | 74,350 |
| `EXACT_FORMULA`(비교용) | 입력 급여로 산식 | 59,080 |
| `MIDPOINT_FORMULA`(비교용) | 행 중간값(3,010,000)으로 산식 | 60,380 |

### 표 데이터

`apps/api/src/modules/payroll/engine/simple-tax-table-2024.ts`에 646행과 10,000천원 행을 둡니다. <개정 2024. 2. 29.> 별표의 금액이고 <개정 2026. 2. 27.> 별표도 금액이 같아(자녀 공제액만 바뀜) 2026-01·2026-03 기준표가 같은 표를 씁니다.

국가법령정보센터가 점검 중이라(2026-11-14) 원문을 직접 받지 못했습니다. 대신 서로 다른 두 공개 자료를 대조했습니다. 하나는 홈택스 "근로소득 간이세액표_2026.03.01.xlsx"를 옮긴 것(`github.com/lcalmsky/k-salary-net` `data/simple-tax-2026-03.json`)이고, 다른 하나는 국가법령정보센터 별표 PDF(flSeq=169798151)를 옮긴 것(`github.com/cho-kyeongseon/net-salary-calculator` `index.html`)입니다. 646행 × 11열과 10,000천원 행이 모두 같았습니다. 행은 빈틈없이 이어지고, 가족 수가 늘면 세액이 늘지 않으며, 급여가 늘면 줄지 않는 것도 테스트로 확인합니다.

## 서버 이전 시 주의

- 공식 간이세액표(소득세법 시행령 별표 2)는 300만원·1인에 74,350원으로 산식 결과(60,380원)와 차이가 큽니다. 2026-11-14에 표를 기준표(`wageIncomeTax.simpleTaxTable`)에 넣고 기본 전략을 `OFFICIAL_TABLE`로 바꿨습니다(D4, #79). 별표 금액이 바뀌면 새 표 파일과 기준표 버전을 더합니다
- 자녀 공제액이 바뀐 2026-03 기준표가 있습니다. 원천세는 지급월 기준표를 쓰므로 2026. 3월 지급분부터 새 공제액입니다
- 비율은 ppm(`withholdingRatePpm`: 800000·1000000·1200000)으로 주고받습니다
- 원천세는 **지급월** 기준표를 씁니다. 귀속월과 지급월 기준표가 다르면 소득세·지방소득세만 지급월 표로 다시 계산합니다
- 중소기업 취업자 감면율은 행 입력(`reduction.ratePpm`)입니다. 청년 90%, 그 외(60세 이상·장애인·경력단절) 70%이고 한도는 과세기간 200만원입니다(조세특례제한법 제30조제1항)
- 조세특례제한법 제30조제1항은 **2026년 12월 31일까지 취업**한 사람만 감면합니다. 그 전에 취업한 사람은 감면기간(3년, 청년 5년)이 끝날 때까지 받지만, 2027년 이후 취업자는 법이 연장되지 않으면 대상이 아닙니다. 2027 기준표를 만들 때 이 일몰의 연장 여부를 다시 확인합니다
