# 연장·야간·휴일 가산수당과 주휴수당

## 요약

가산수당은 근무 시간 × 통상시급 × 회사가 정한 지급배수입니다. 5인 이상 기본 배수는 연장 1.5, 야간 0.5(가산분), 휴일 1.5, 휴일연장 2이고, 5인 미만은 가산이 없습니다(1, 0, 1, 1). 통상시급은 통상임금 포함 항목 월합계 ÷ 월 소정근로시간(주 40시간이면 209시간)이고 시급제는 시급입니다. 시급·일급제는 주휴수당(1일 주휴시간 × 시급 × 주 수)을 따로 줍니다. 월급제의 지각·조퇴·결근은 시간 × 통상시급을 뺍니다.

## 현행 위치

- 화면: 급여 설정 > 급여 지급 조건의 "수당 지급배수", 근로 행의 근무 시트
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/working-time.ts`, `payroll-row.ts`

## 로직

```
통상시급 단가 = (기본급 + 통상임금 포함 항목, 일할 전) ÷ (월 소정근로시간 × 60분)   // 반올림하지 않고 분수로 둠
가산수당 = 분 × 단가 × 배수(ppm)                                                  → 원 미만 절사
주휴수당 = 1일 주휴시간(dailyRestMinutes, 기본 480분) × 시급 × 주휴 주 수(weeklyHolidayWeeks)
1일 주휴시간 = min(8시간, 주 소정근로시간 ÷ 40 × 8)   // 주 15시간 미만이면 0. 엔진은 계산된 분을 입력으로 받습니다
```

## 근거

- 스펙 4.8(`docs/reference/spec/payroll.md:437-449`): 기본 배수 표 "연장 1.5 / 1, 야간 0.5 (가산분만) / 0, 휴일 1.5 / 1, 휴일 연장 2.0 / 1", "배수는 회사 설정값(`payroll_terms`)을 쓴다", "근태 공제: 지각·조퇴·결근 시간 × 통상시급으로 추정"
- 스펙 4.7(`:428-435`): "통상시급 = (통상시급 포함 항목 월합계) ÷ 월 소정근로시간(유급 주휴 포함). 주 40시간이면 … **209시간**"
- 스펙 4.9(`:451-456`): "1일 주휴시간 = 주 소정근로시간 ÷ 소정근로일수 … 최대 8시간", "월급제는 기본급에 포함 … 별도 지급이 필요한 것은 **시급제**와 일급제"
- 매뉴얼 `alfred-manual/08-설정/03-급여-설정.md:146-162`: "5인 미만 … 근로기준법 제56조의 적용을 받지 않으므로", "항목별 가산 배수는 회사 정책에 따라 다를 수 있으므로 정책 확인 후 설정"
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:297-360`)

## 서버 이전 시 주의

- 근무 시간은 분 단위 정수로 받습니다. 현행·재설계 전 구현은 소수 시간(1.5시간)이었고, 주휴시간을 소수 둘째 자리로 반올림했습니다. 지금은 분으로 반올림하므로 단시간 근로자의 주휴시간이 1분 이내로 다를 수 있습니다
- 배수는 ppm(`overtimeRatePpm: 1500000`)입니다. 현행 `fixed_*_multiplier_x100`(150)을 대신합니다
- 고정 연장근로(포괄임금)의 초과분 지급과 `actual`/`additional` 입력 타입은 아직 없습니다
- 회사 규모를 바꾸고 배수를 보내지 않으면 새 규모의 기본 배수로 바꿉니다(매뉴얼 FAQ `:269-271`)
