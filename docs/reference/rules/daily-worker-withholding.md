# 일용근로소득 원천징수

## 요약

일용근로자는 하루 지급액에서 15만원을 빼고 6%를 곱한 뒤 55%를 세액공제합니다. 원천징수세액이 1,000원 미만이면 걷지 않습니다(소액부징수). 4대보험은 고용보험만 기본으로 공제합니다.

## 현행 위치

- 화면: 급여 > 일용 소득 탭(지급액, 근무일자 다중 선택)
- 번들: 계산식 없음. 제외 사유 문구 "월 8일 또는 60h 미만"만 있습니다(스펙 4.1)
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/withholding.ts`

## 로직

```
일급 = 행 지급액 ÷ 근무일수(균등 분할)
과세표준(일) = max(0, 일급 − 150,000)
산출세액 = 과세표준 × 6%
소득세 = 산출세액 − 산출세액 × 55%   → 합계가 1,000원 미만이면 0
지방소득세 = 소득세 × 10%
고용보험 = 지급액 × 0.9%
```

- 월 8일 이상이거나 60시간 이상이면 국민연금·건강보험 대상이라는 경고(`DAILY_WORKER_SOCIAL_INSURANCE_REQUIRED`)를 붙입니다

## 근거

- 스펙 4.3(`docs/reference/spec/payroll.md:377-389`): "과세표준 = max(0, 일급여 − 150,000)", "원천징수 소득세 = 산출세액 − 산출세액 × 55%", "원천징수세액이 1,000원 미만이면 0 (소액부징수)", "화면은 행 단위 총액과 근무일자 다중 선택이므로 **균등 분할로 추정**"
- 스펙 4.1: "일용근로자: 고용보험만 기본으로 적용한다. 월 8일 이상 또는 60시간 이상이면 국민연금과 건강보험 대상"
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:386-405`)

## 서버 이전 시 주의

- 소액부징수를 날마다 볼지 지급 건마다 볼지 정해지지 않았습니다. 지금은 행 합계로 봅니다
- 사업주·동거친족이면 행 입력 `employmentInsuranceExempt`로 고용보험을 뺍니다
- 일용근로소득 지급명세서에 행 단위 원본(성명, 근무일수, 지급액, 세액)이 필요하므로 행을 지우지 않고 보존합니다
