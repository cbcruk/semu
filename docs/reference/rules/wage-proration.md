# 일할계산

## 요약

월급제 직원이 임금산정 기간 중에 입사하거나 퇴사하면 기본급(과 일할 대상 수당)을 재직일수 ÷ 기간 역일수로 나눠 지급하고 원 미만을 버립니다.

## 현행 위치

- 화면: 근로 행의 "일할계산 요청" 체크박스
- 매뉴얼: 중도 입사자·퇴사자 일할계산
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/working-time.ts`의 `prorate`

## 로직

```
일할 금액 = 월 금액 × 지급일수 ÷ 기간 일수   → 원 미만 절사
```

- 정기 대장을 만들 때 HR의 입사일·퇴사일이 임금산정 기간 안에 있으면 서버가 역일 기준 일할 입력을 넣습니다
- 행에서 직접 고칠 수 있고, 소정근로일 기준(`SCHEDULED_DAYS`)도 받습니다

## 근거

- 스펙 4.10(`docs/reference/spec/payroll.md:458-461`): "중도 입사·퇴사, 수습, 휴직이면 자동으로 일할한다. legacy에서는 '일할계산 요청' 체크로 켠다", "공식은 `월급 × 재직일수 ÷ 해당월 역일수`(역일 기준)와 소정근로일 기준이 모두 쓰인다. **어느 방식인지 확인 필요**"
- 매뉴얼 `manual/05-급여/01-급여-관리/02-급여-급여-관리-근로-소득-입력.md:16-18`: "일할계산 필드에 **요청 체크박스를 선택**하면 계산 시 일할계산으로 처리됩니다"
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:248-251`, `:315-318`)

## 서버 이전 시 주의

- 현행은 사용자가 체크해야 일할하지만, 재설계는 HR 입·퇴사일로 서버가 기본값을 넣습니다. 체크를 잊어 전액 지급되는 실수를 막습니다
- 수습·휴직 일할은 HR이 기간을 주지 않아 아직 자동으로 넣지 않습니다
- 기본 방식(역일)은 확인이 필요합니다
