# 사업소득 원천징수

## 요약

사업소득은 지급액의 3%를 소득세, 그 10%를 지방소득세로 원천징수합니다(합계 3.3%). 원 미만을 버리고 소득세가 1,000원 미만이면 걷지 않습니다. 세후 금액을 입력하면 세전 지급액을 역산합니다. 예술인·노무제공자 업종은 고용보험(근로자 0.8%)을 더 뺍니다.

## 현행 위치

- 화면: 급여 > 사업 소득 탭(업종코드, 지급액, 세금공제 전/후)
- 번들: 업종코드 조회 `/api/payroll/business-income-types/`, `special-occ-types`. 계산식 없음
- 재설계 전 구현: `apps/api/legacy/src/modules/payroll/engine/withholding.ts`

## 로직

```
소득세 = 지급액 × 3%       → 원 미만 절사, 1,000원 미만이면 0
지방소득세 = 소득세 × 10%   → 원 미만 절사
세후 입력: 지급액 = 실지급 ÷ (1 − 0.033)에서 시작해 세후가 입력과 같아지는 금액을 찾습니다
예술인 고용보험 = 지급액 × 0.8%
```

## 근거

- 스펙 4.4(`docs/reference/spec/payroll.md:391-396`): "소득세 = 지급액 × 3%, 지방소득세 = 소득세 × 10%(= 0.3%). 합계 3.3%. 원 미만 절사하고, 소득세가 1,000원 미만이면 소액부징수", "`세금공제 여부`가 '세금공제후'(세후 지급액 입력)라면 역산한다: `지급액 = 실지급 / (1 − 0.033)`(추정)"
- 스펙 4.1: "예술인·노무제공자 고용보험 0.8% (본인) … **확인 필요**"
- 원문 확인(2026-11-05): 예술인 고용보험료율 1천분의 16(보험료징수법 시행령 제56조의5제2항), 예술인·사업주 2분의 1씩(법 제48조의2제8항제2호, 제13조제2항 준용)이라 본인 0.8%입니다. 보수액은 소득에서 비과세와 고용노동부장관 고시 필요경비를 뺀 금액입니다(시행령 제56조의5제1항). 엔진은 필요경비를 빼지 않습니다
- 재설계 전 구현의 검증 사례(`apps/api/legacy/test/payroll/engine.test.ts:407-419`)

## 서버 이전 시 주의

- 업종코드는 소득세법 시행규칙 별지 제23호서식(2) <개정 2026. 3. 20.>의 업종구분코드 표 40개입니다(`verified: true`, 2026-11-07 확인). 현행 화면의 "기타자영업(프리랜서)"는 서식의 `940909` 기타인적용역자입니다
- 예술인 필요경비(재단 안내 25%)·기준보수 하한(80만원)·월평균소득 50만원 미만 적용 제외는 고시 원문을 찾지 못해 넣지 않았습니다(학습용 가정)
- 예술인·노무제공자 고용보험은 행에서 대상이라고 표시했을 때만 뺍니다. 업종의 구분(`ARTIST`·`SPECIAL`)은 현행 화면의 힌트일 뿐 계산에 쓰지 않습니다(2026-11-07). 노무제공자 요율을 따로 두지 않고 예술인 요율(0.8%)을 씁니다. 노무제공자 고용보험료율은 1천분의 16을 노무제공자와 사업주가 반씩 내므로(고용보험 및 산업재해보상보험의 보험료징수 등에 관한 법률 시행령 제56조의6제4항, 2025-12-23 시행 대통령령 제35935호를 2차 사이트에서 확인) 근로자 몫이 예술인과 같은 0.8%입니다. **학습용 가정:** 노무제공자 보수는 직종별 필요경비(고용노동부 고시)를 뺀 금액이어야 하지만, 고시 원문을 확인하지 못해 엔진은 지급액 전체에 0.8%를 적용합니다
- 비거주자 세율(조세조약)은 지원하지 않습니다
